# Arsenal

Wallet-first credit card coverage, pathways, and spend routing. Numbers come from deterministic engines.

```bash
npm install
npm run dev
npm test
```

http://localhost:3000 — **Explore demo arsenal** for a seeded wallet.

Engines live under `src/lib/engines/`. Routes: `/onboarding` `/arsenal` `/coverage` `/guide` `/calendar` `/router` `/buy` `/spending` `/optimize` `/simulate` `/compare` `/pathway` `/discover` `/welcome` `/benefits` `/fees` `/renewal` `/timeline` `/settings` `/admin`.

No PAN/CVV/SSN. Not financial advice.
